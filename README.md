# Rapport de stage — 4ème année Cycle Ingénieur

Bienvenue sur le dépôt lié à mon rapport de stage de 4ème année en **Robotique** à **Polytech Nice Sophia**, effectué au sein de l'entreprise **Altran Technologies** à Toulouse.

## 📁 Structure de la documentation

Afin de faciliter la lecture et la prise en main du projet, la documentation est structurée comme suit :

*   [**README_Intro_Pipeline.md**](./README_Intro_Pipeline.md) : Présente le projet dans sa globalité, le contexte ainsi que les objectifs visés.
*   [**README_Installation_Guide.md**](./README_Installation_Guide.md) : Guide pas à pas pour configurer l'environnement et reproduire le projet.

## 🎥 Démonstrations vidéo

Le projet s'appuie sur de l'**apprentissage par imitation** (*Imitation Learning*) entraîné à partir de données téléopérées enregistrées via un **casque VR**.

*   **Simulation** : Visualiser la vidéo [`sim_ai.mp4`](./sim_ai.mp4) pour observer les résultats de l'IA en environnement simulé.
*   **Robot réel** : Visualiser la vidéo [`real_ai.mp4`](./real_ai.mp4) pour voir le comportement de l'IA déployée sur le système réel.
